# WIREFRAMES - Parcours DevOps Guide

## 1. Objectif

Ces wireframes textuels cadrent les ecrans principaux avant la realisation des maquettes haute fidelite sur Figma.

```text
| Logo            Navigation                                   |
+--------------------------------------------------------------+

+--------------------------------------------------------------+
| Bloc promesse | Bloc progression | Bloc contenu              |
+--------------------------------------------------------------+
| Footer                                                      |
+--------------------------------------------------------------+
```

## 10. Utilisation dans Figma

Ces wireframes servent de base pour :

- dessiner les frames Figma
- organiser le parcours utilisateur
- definir les zones de contenu
- preparer le prototype interactif
