# Benchmark visuel - Parcours DevOps Guide

## Objectif

Identifier des references visuelles utiles pour une application pedagogique orientee progression, lisibilite et public technique.

## Reference 1 - roadmap.sh

- URL : [https://roadmap.sh/](https://roadmap.sh/)
- Ce qui inspire :
  - structure claire de parcours
  - logique de progression par etapes
  - vocabulaire adapte a un public technique
- Ce que je retiens :
  - presenter les modules comme un parcours ordonne
  - afficher le niveau ou la position de chaque module
- Ce que je ne retiens pas :
  - une interface trop dense pour la V1

## Reference 2 - Duolingo

- URL : [https://www.duolingo.com/](https://www.duolingo.com/)
- Ce qui inspire :
  - progression visible
  - feedback immediat
  - parcours rassurant pour les debutant·es
- Ce que je retiens :
  - montrer clairement ce qui est termine et ce qui reste a faire
  - encourager sans surcharge visuelle
- Ce que je ne retiens pas :
  - la gamification forte, hors perimetre V1

## Reference 3 - Linear

- URL : [https://linear.app/](https://linear.app/)
- Ce qui inspire :
  - interface sobre
  - hierarchie visuelle propre
  - densite maitrisee pour un produit technique
- Ce que je retiens :
  - un espace d'administration minimal et lisible
  - des cartes, badges et statuts discrets
- Ce que je ne retiens pas :
  - une interface trop orientee gestion d'equipe

## Reference 4 - GitHub Docs

- URL : [https://docs.github.com/](https://docs.github.com/)
- Ce qui inspire :
  - excellente lisibilite des contenus
  - structure documentaire claire
  - ton adapte a un public developpeur
- Ce que je retiens :
  - une page detail module qui privilegie la lecture
  - une organisation simple des ressources associees
- Ce que je ne retiens pas :
  - la profondeur documentaire trop importante pour une V1

## Synthese

Le produit doit combiner :

- la logique de parcours de `roadmap.sh`
- la progression explicite de `Duolingo`
- la sobriete UI de `Linear`
- la lisibilite contenu de `GitHub Docs`

## Direction retenue

La direction visuelle vise une interface :

- claire
- pedagogique
- sobre
- orientee progression
- adaptee a un public technique debutant
